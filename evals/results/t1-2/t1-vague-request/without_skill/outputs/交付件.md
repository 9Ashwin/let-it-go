- `greeter/slug.go` — 新增导出函数 `Slug`：

  ```go
  func Slug(name string) string {
      return strings.ToLower(strings.Join(strings.Fields(name), "-"))
  }
  ```

  `strings.Fields` 按 Unicode 空白切分并天然丢掉首尾空白、折叠连续空白，`Join` 补连字符，`ToLower` 实现大小写不敏感。
