# PRD: 名字转 URL 友好 slug

给 greeter 模块加一个纯函数，把名字转成页面锚点用的 slug。需求只点名三条规则：大小写不敏感、
空白折成连字符、首尾不留。无远端（`gh` 不可用），本文件即契约载体。

## goal

greeter 包新增 `func Slug(name string) string`：输出小写、把连续空白折成单个连字符、去掉首尾连字符，
供页面锚点使用。

## acceptance

- [ ] `Slug("Ada Lovelace")` == `"ada-lovelace"`（大小写折叠 + 空白折成连字符）
- [ ] 连续空白（空格 / 制表 / 换行）折成**单个**连字符：`Slug("A \t B\nC")` == `"a-b-c"`
- [ ] 首尾空白不产生首尾连字符：`Slug("  Ada  ")` == `"ada"`
- [ ] 空串与纯空白输入返回 `""`（不是 `"-"`，也不兜底 `"world"`）
- [ ] `make check` 通过，且 `Makefile` 与 `greeter/greet_test.go` 逐字节不变（sha256 前后一致）

## invariants

- `Makefile`、`greeter/greet_test.go` 是冻结验收基线，逐字节不变；新行为测试只进新文件 `greeter/slug_test.go`
- `Greet` 现有行为不变
- 不引入第三方依赖（`go.mod` 的 `require` 保持为空）

## unknowns

- 非空白特殊字符（逗号、感叹号等标点）是否剔除 —— [Assumption] 不剔除。需求只点名空白折叠与大小写；
  URL 片段允许这些字符。需要更严格的 URL 安全时另开一条。
- 连续空白折成一个还是每个空白一个连字符 —— [Assumption] 折成单个连字符。
- 空 / 纯空白输入的返回 —— [Assumption] 返回 `""`；`Slug` 是纯转换，兜底 `"world"` 是 `Greet` 的职责。
- 函数名与签名 —— [Assumption] `func Slug(name string) string`，与 `Greet` 同包同风格。
- 输入里已有的连字符 —— [Assumption] 原样保留，不做额外折叠。

## 需要你知道的假设

需求只点名了三条规则，其余我按下面默认推进并标了 `[Assumption]`，不合预期就当修订：

1. **非空白标点不剔除**——`Slug("Hi, Ada!")` 得到 `hi,-ada!`。URL 片段允许这些字符；要更严格的 URL 安全得另开一条。
2. **连续空白折成单个连字符**，不是每个空白一个。
3. **空 / 纯空白输入返回 `""`**，不做 `"world"` 兜底（那是 `Greet` 的职责）。

另外「大小写不敏感」我落成了**输出统一小写**，所以 `"Ada"` 与 `"ada"` 得到同一个 slug。
