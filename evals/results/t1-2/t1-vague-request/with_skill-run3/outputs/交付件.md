# PRD: 名字转 URL 友好 slug

greeter 模块需要一个纯函数，把名字转成页面锚点用的 URL 友好 slug。

## goal

greeter 模块导出一个纯函数 `Slug(name string) string`，把任意名字转成 URL 友好 slug：输出小写、空白折成连字符、首尾无连字符。

## acceptance

- [ ] **大小写归一**：`Slug("Ada Lovelace")`、`Slug("ADA LOVELACE")`、`Slug("ada lovelace")` 三者相等，且等于 `"ada-lovelace"`。（反例观测：任一不等，或结果含大写即失败）
- [ ] **空白折叠**：连续空白（空格 / 制表符 / 换行）折成**单个** `-`：`Slug("a  b\tc\nd")` == `"a-b-c-d"`。（反例观测：结果出现 `--`，或保留原空白即失败）
- [ ] **首尾不留**：`Slug("  hello  ")` == `"hello"`；空串 `Slug("")` == `""`、全空白 `Slug("  \t\n")` == `""`。（反例观测：结果带首尾 `-`，或全空白结果非空即失败）
- [ ] **门禁绿且基线冻结**：改动后 `make check` 通过；`Makefile` 与 `greeter/greet_test.go` 逐字节不变。

## invariants

- `Makefile` 与 `greeter/greet_test.go` 是冻结基线，逐字节不变
- `Slug` 是纯函数：无副作用、无外部依赖、不引入新的 module 依赖
- `Greet` 的签名与行为不变

## unknowns

- 非字母数字字符（标点 / Unicode / emoji）如何处理 —— [Assumption] 本次只实现题面三条规则，不额外剥离或转写；需要时另开
- 函数命名与落点 —— [Assumption] `Slug(name string) string`，实现放新文件 `greeter/slug.go`，测试放新文件 `greeter/slug_test.go`
- 大小写归一手段 —— [Assumption] 标准库 `strings.ToLower`，零新依赖

## 关键决策

- 大小写归一走标准库 `strings.ToLower`，零新依赖
- 用 `strings.Fields` 切分：连续空白（空格 / 制表 / 换行）天然折成**单个**连字符，且不产生首尾连字符
- 末尾再 `strings.Trim(..., "-")` 兜底「首尾不留」：输入自带的首尾连字符也一并去掉
- 非空白标点（逗号、感叹号等）**不剔除**：题面只点名空白折叠与大小写，需要更严格的 URL 安全时另开
- 空 / 纯空白输入返回 `""`，不兜底 `"world"`——兜底是 `Greet` 的职责
- 实现放新文件，`greet.go` 不动；新测试只进新文件，冻结基线零改动
