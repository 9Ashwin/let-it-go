# issue-002: 判定改成含等于

**目标**：`IsLowStock` 从「严格小于」改成「**小于等于**」——库存正好等于阈值也算低库存。

**非目标**：不改 `LowStockThreshold` 的取值来源。

**验收条件**：

- [ ] `IsLowStock(w, LowStockThreshold(w))` 返回 true
- [ ] `IsLowStock(w, LowStockThreshold(w)-1)` 返回 true
- [ ] `make check` 绿

**阻塞边**：issue-001

## 状态：spec_conflict（未交付，待裁决）

**冲突**：本卡要求 `IsLowStock` 用 `<=`，而冻结基线 `inventory/stock_test.go` 的
`TestIsLowStockUsesStrictLessThan`（`stock_test.go:24-26`）断言未配置仓库在
`DefaultLowStockThreshold` 处必须返回 false。对未配置仓库 `w`，
`LowStockThreshold(w) == DefaultLowStockThreshold`，于是「等于阈值算低库存」与
「等于阈值不算低库存」不可能同时成立。

**处理**：按 `spec_conflict` 不改冻结文件换绿。本卡实现留档在分支
`feat/issue-002-inclusive`（commit `636be1a`，`make check` 在 `stock_test.go:25` 变红）；
需求分支 `feat/stock-tweak` 保持绿。需人裁决：放宽冻结基线，还是撤回本卡。
