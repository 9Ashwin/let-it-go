### `requirements/001-per-warehouse-low-stock-threshold/documents/prd-per-warehouse-low-stock-threshold.md`

# PRD — 按仓库配置低库存阈值

作用域：`requirements/001-per-warehouse-low-stock-threshold/`。工作状态（契约）的载体是
`issues/issue-001-*.md`；本文件是它的投影，冲突时以 issue 正文为准。

## goal

让每个仓库能有自己的低库存阈值：运维直接编辑 `config/thresholds.json` 即生效、无需重新构建；
未在该文件里配置的仓库继续走原来的 `DefaultLowStockThreshold`。受益方是运营与仓库管理员——
现在所有仓库共用一个全局值，无法按仓单独调。

## acceptance

1. **配置生效**：`config/thresholds.json` 里给某仓库指定的阈值，`LowStockThreshold(warehouse)`
   返回该值，`IsLowStock` 与 `LowStockWarehouses` 按它判定。
   证伪观测：配置 `{"beijing": 10}` 后，`LowStockThreshold("beijing") != 10`，或
   `IsLowStock("beijing", 9) != true`、`IsLowStock("beijing", 10) != false`。
2. **未配置回退默认**：配置里没有的仓库返回 `DefaultLowStockThreshold`。
   证伪观测：配置 `{"beijing": 10}` 时 `LowStockThreshold("wuhan") != DefaultLowStockThreshold`。
3. **改文件即生效，无需重建**：同一份已编译二进制，在两次运行之间只修改
   `config/thresholds.json`，读到的阈值随之改变。
   证伪观测：编译一次探针，先读到 3、把文件改成 7 后（不重新编译）再读仍为 3。
4. **缺失/损坏安全回退**：文件不存在或 JSON 非法时不 panic，全部仓库回退默认值。
   证伪观测：把文件写成非法 JSON 后调用返回非默认值或进程崩溃。

## invariants

- `DefaultLowStockThreshold` 仍为 5。
- 三个公开函数签名与语义不变：`LowStockThreshold(string) int`、`IsLowStock(string, int) bool`、
  `LowStockWarehouses(map[string]int) []string`（后者仍返回排序后的仓库名）。
- 现有 `inventory/stock_test.go` 逐字节不变（fixture 冻结基线）。
- 只改本仓库内的文件。

## unknowns

- 配置 schema 取扁平 `{"<warehouse>": <threshold>}`。`[Assumption]` 仓库没有既有格式约定，
  选最小可读结构；默认值不进文件，避免与 Go 常量重复真相。
- 配置定位取「从当前工作目录向上查找 `config/thresholds.json`」。`[Assumption]` 需同时兼容
  从仓库根启动与 `go test` 以包目录为工作目录两种情形；找到才读，找不到即回退默认。
- 每次调用重新读取文件，不做缓存。`[Assumption]` 该文件很小，换取「改文件立即生效」这一
  硬约束的最简实现；不引入 mtime 缓存。
- 负数等非法阈值不做额外校验，按文件原值采用。`[Assumption]` 未要求校验。

## human_checkpoint

无。未触碰公开 API / 兼容性 / 数据迁移 / 权限 / 不可逆操作；配置载体与路径解析方式由实现方决定。
