## 落地方式

**配置格式** — `config/thresholds.json`，就是「仓库名 → 阈值」的扁平 JSON 对象：

```json
{
  "beijing": 10,
  "shanghai": 3
}
```

**运行时读取（关键约束）** — 没有用 `go:embed`，而是每次调用 `LowStockThreshold` 时用 `os.ReadFile` + `json.Unmarshal` 现读现解析。所以运维改完文件保存即生效，既不用重新构建，也不用重启进程。

**回退语义** — 用 `map` 查存的 `ok` 判断，而不是判零值：
- 没列出的仓库 → `DefaultLowStockThreshold`（5）；
- 配成 `0` 是有效配置（该仓库永不判低库存），不会被误当成「未配置」；
- 文件缺失或 JSON 损坏 → 也按「没配置」回退默认，不会 panic。

**路径定位** — 从当前工作目录逐级向上找 `config/thresholds.json`。这样从仓库根跑二进制、和 `go test`（cwd 在 `inventory/`）都能找到同一份文件。部署时工作目录不在仓库根的话，用环境变量 `INVENTORY_THRESHOLDS_FILE` 指过去。
