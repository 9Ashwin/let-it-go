## 交付物

**代码**
- `greeter/slug.go` — 新增导出纯函数：
  ```go
  func Slug(name string) string {
      return strings.Join(strings.Fields(strings.ToLower(name)), "-")
  }
  ```
  `ToLower` 管大小写不敏感，`Fields` 折叠任意空白（含 tab/换行/Unicode 空白）并天然去掉首尾，`Join` 折成单个连字符。
