# PRD: 名字 → URL 友好 slug

## 目标

greeter 模块提供一个纯函数，把名字转成可用作页面锚点的 URL 友好 slug。

## 验收

- **大小写不敏感**：`Slug("Ada")` 与 `Slug("ADA")` 结果相同，输出为小写。
- **空白折成连字符**：名字中的空白（空格、制表、换行等）连续段折叠为单个 `-`。
- **首尾不留**：输出不以 `-` 开头或结尾。
- **空输入**：空串或纯空白返回空串。

## 不变量

- 纯函数：不读写全局状态，不返回 error。
- 除大小写与分隔符外不改动名字内容：非空白字符原样保留，含标点与 Unicode 字母。

## 假设

- [Assumption] 标点等非空白字符是否剔除不在本次诉求内，先原样保留；如需剔除另开需求。
- [Assumption] 名字中已有的 `-` 视作分隔符参与折叠，避免出现连续或首尾连字符。

## 未知 / 待确认

- 非拉丁名字（如中文）是否要音译或百分号编码——本次不做，原样保留。

## 人工检查点

- 无。改动由 `make check` 自动验收。
