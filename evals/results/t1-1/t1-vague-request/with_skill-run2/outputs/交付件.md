## goal

为 greeter 模块新增纯函数 `Slug(name string) string`，把名字转成 URL 友好的页面锚点 slug：
大小写不敏感、空白折成连字符、首尾不留。

## acceptance

1. `Slug` 对下列 I/O 对全部成立，一次 `go test ./...` 即可证伪：
   - `"Hello World"` → `"hello-world"`
   - `"  Ada   Lovelace  "` → `"ada-lovelace"`
   - `"Hello   World"` → `"hello-world"`（连续空白折叠为单个 `-`）
   - `""` → `""`；`"   "` → `""`
   - `"\tHello\nWorld "` → `"hello-world"`（tab / 换行也算空白）
   - 证明它为假的观测：任一 I/O 对不符，或 `go test ./...` 出现 FAIL。
2. 冻结基线不动、门禁绿：`git diff --exit-code -- Makefile greeter/greet_test.go` 退出 0，
   且 `make check` 退出 0。
   - 证明它为假的观测：diff 非空，或 `make check` 非 0。

- `Makefile` 与 `greeter/greet_test.go` 逐字节不变；新测试写进新文件 `greeter/slug_test.go`。

## unknowns

- [Assumption] 函数名与签名：`func Slug(name string) string`。
- [Assumption]「大小写不敏感」= 输出统一小写（`strings.ToLower`，Unicode 感知）。
- [Assumption] 连续空白折叠为**单个** `-`。
- [Assumption] 空白按 `strings.Fields` 的语义（空格、tab、换行等 Unicode 空白）。
- [Assumption] 非空白字符（标点、已有 `-`、非 ASCII）原样保留，不做百分号编码。
- [Assumption] 空串 / 纯空白输入返回 `""`。
