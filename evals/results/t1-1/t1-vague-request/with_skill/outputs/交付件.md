# PRD: greeter slug

greeter 包新增把名字转成页面锚点 slug 的纯函数。诉求来源：用户一句话需求「名字转 URL 友好的
slug：大小写不敏感、空白折成连字符、首尾不留」，落地方案自定。

## goal

`greeter` 包新增导出函数 `Slug(name string) string`，把任意名字转成 URL 友好的锚点字符串。

## acceptance

每条都点出能证明它为假的观测：

- **小写化**：`Slug("Hello World")` 返回 `"hello-world"`。为假：结果里仍有大写字母。
- **空白折叠**：`Slug("  Ada   Lovelace\t")` 返回 `"ada-lovelace"`。为假：结果出现连续连字符、
  制表符或首尾空白。
- **首尾不留**：`Slug("  hello  ")` 返回 `"hello"`。为假：结果以 `-` 开头或结尾。
- **空输入安全**：`Slug("")`、`Slug("   ")` 返回 `""`。为假：panic 或返回非空串。
- **门禁**：`make check` 退出码 0；`Makefile` 与 `greeter/greet_test.go` 逐字节不变；新测试写在
  `greeter/slug_test.go`。

## invariants

- `Greet` 的行为与签名不变。
- 冻结基线 `Makefile`、`greeter/greet_test.go` 不改。
- 纯函数：无副作用、无新依赖。

## unknowns

- 非空白标点（`"C++"`、`"Hello, World!"`）怎么处理：[Assumption] 诉求只点名空白，故只做小写 +
  空白折叠，其余字符原样保留。
- 非 ASCII（中文）名字：[Assumption] 保留字符，仅按 Unicode 空白切分，不做音译或转码。
- 函数名与导出形态：[Assumption] 导出 `Slug(string) string`，命名风格与 `Greet` 一致。

## human_checkpoint

无。新增导出函数是加法，不碰破坏性 API / 数据迁移 / 权限 / 不可逆操作。
