# PRD: 名字 → URL 友好 slug

背景：greeter 模块需要一个把名字转成页面锚点用 slug 的纯函数。

## goal

为 `package greeter` 增加 `Slug(name string) string`：把名字转成大小写不敏感、空白折成连字符、
首尾不留连字符的 URL 友好 slug。

## acceptance

- **A1 大小写折叠**：`Slug("Hello World")` 与 `Slug("HELLO WORLD")` 都等于 `"hello-world"`。
  证伪观测：任一结果不是全小写。
- **A2 空白折叠且首尾不留**：`Slug("  Hello   World\t")` 等于 `"hello-world"`——连续空白折成单个
  连字符，首尾空白不产生连字符。
  证伪观测：结果里出现由空白产生的连续 `--`，或首/尾因空白出现 `-`。输入自带的标点（含连字符）
  按下方 unknowns 原样保留，不在本条范围内。
- **A3 空输入**：`Slug("")` 与 `Slug("   ")` 都等于 `""`。
  证伪观测：返回非空。

A1–A3 由同一次观测覆盖：`go test ./...` 中表驱动用例 `TestSlug`（写入新文件 `greeter/slug_test.go`）。

- `make check` 绿。

## 落地结果

新增纯函数（`greeter/slug.go`）：

```go
func Slug(name string) string {
	return strings.Join(strings.Fields(strings.ToLower(name)), "-")
}
```

`strings.Fields` 一次完成"连续空白折一个 + 首尾丢弃"，`ToLower` 负责大小写，`Join` 补连字符。新测试写在新文件 `greeter/slug_test.go`，没碰冻结基线。
