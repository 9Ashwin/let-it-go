## 改动

**新增 `greeter/slug.go`** — 实现 `Slug`：

```go
func Slug(s string) string {
	return strings.Join(strings.Fields(strings.ToLower(s)), "-")
}
```

`strings.Fields` 顺带解决了首尾空白与连续空白两个验收点（按 Unicode 空白切分，多个空白自然折成一个分隔符）。
