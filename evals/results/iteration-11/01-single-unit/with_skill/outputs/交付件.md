# PRD: 按仓库配置低库存阈值

## 评审状态

## 简介

库存服务目前只有一个全局常量 `DefaultLowStockThreshold`，所有仓库共用。业务需要按仓库设置低库存阈值：已配置的仓库使用自己的阈值，未配置的仓库沿用默认值。阈值来源是仓库内一个 JSON 文件。

## 目标

- 每个仓库可以拥有独立的低库存阈值。
- 未配置的仓库继续沿用 `DefaultLowStockThreshold`（当前为 5），行为不变。
- 配置来源固定为 `inventory/thresholds.json`，格式 `{"shanghai": 20}`。
- 文件不存在、无法读取，或其中没有该仓库时，回退默认值，不 panic、不报错。
- 保持现有公开函数签名不变（`LowStockThreshold(string) int` 等）。
- `make check`（build + test + vet）绿。

## 用户故事

### US-001: 已配置仓库使用自己的阈值

**Description:** 作为库存业务方，我想要给某个仓库单独设置低库存阈值，以便不同仓库按各自的补货节奏触发预警。

**Acceptance Criteria:**

- [ ] 当 `inventory/thresholds.json` 含 `{"shanghai": 20}` 时，`LowStockThreshold("shanghai")` 返回 `20`
- [ ] `IsLowStock("shanghai", 19)` 为真，`IsLowStock("shanghai", 20)` 为假（严格小于）
- [ ] `LowStockWarehouses` 对该仓库按新阈值判定
- [ ] `make check` 通过

### US-002: 未配置仓库回退默认值

**Description:** 作为维护者，我想要没配的仓库保持原行为，以便上线按仓库配置时不改变现有预警。

**Acceptance Criteria:**

- [ ] `inventory/thresholds.json` 不存在时，任意仓库返回 `DefaultLowStockThreshold`
- [ ] 文件存在但仓库不在其中时，该仓库返回 `DefaultLowStockThreshold`
- [ ] 文件内容不是合法 JSON 时，同样回退 `DefaultLowStockThreshold`，不 panic
- [ ] `make check` 通过

### US-003: 按仓库阈值的端到端测试

**Description:** 作为 QA 工程师，我想要一个覆盖「读配置 → 判定低库存」整条路径的自动化测试，以便接住回归。

**Acceptance Criteria:**

- [ ] 测试准备一个含已配置仓库的 `inventory/thresholds.json`，断言 `LowStockThreshold` 与 `IsLowStock` 的返回
- [ ] 测试覆盖「文件缺失 / 仓库未配置 / 非法 JSON」三类回退路径
- [ ] 测试自建数据、自清理，可重复运行
- [ ] 测试在 `make check` 里通过

## 功能需求

- FR-1: 系统必须从 `inventory/thresholds.json` 读取按仓库的阈值映射。
- FR-2: `LowStockThreshold(warehouse)` 必须返回该仓库在映射里的值（若存在）。
- FR-3: 若映射中不存在该仓库，`LowStockThreshold` 必须返回 `DefaultLowStockThreshold`。
- FR-4: 若 `thresholds.json` 不存在或无法解析，系统必须视作空映射并回退默认值，不得 panic。
- FR-5: `IsLowStock` 必须继续使用严格小于比较。
- FR-6: 公开函数签名必须保持不变。

## 偏离（Deviations）

- US-003 AC 字面写「准备一个含已配置仓库的 `inventory/thresholds.json`」，实现改为经注入点指向 `t.TempDir()` 下的同名文件。原因评审发现"测试直接读写真实配置文件"会留下残留、并发互踩，并可能在真实配置命中冻结测试用的仓库时弄红门禁。行为覆盖不变，且更安全。
- `/ship-it` 远端模式在有 origin 时优先走 PR，本仓库虽有本地 bare remote，但 `gh` 不可用，故按本地模式合入，不 push、不建远端。

## 权衡（Tradeoffs）

- 每仓库一次文件读 vs 缓存：当前选不缓存（改动即时生效、实现简单）；`LowStockWarehouses` 扫描 N 个仓库会读 N 次文件，已记为 PRD 的 `[Assumption]`，量大时再改。
- 路径解析：module 根解析覆盖了本项目所有运行方式；部署 cwd 不在 module 内时会退回 cwd 相对路径，属 PRD 「未决问题」记录的部署期残余风险。
- 非法 JSON 静默回退 vs 报错：公开函数无 error 返回值，选回退默认值，保证调用方行为不破。

## 待确认（Open Questions）
